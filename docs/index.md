## この授業について

データに潜む重要な情報を明らかにする方法として多変量解析を位置づけ、基本的な考え方と代表的な手法、社会における活用法を学ぶ授業です。予測・要因探求のための手法（重回帰分析、二項ロジスティック回帰分析、分散分析など）と、複雑な情報をまとめ分類するための手法（因子分析、主成分分析、クラスター分析、構造方程式モデリング）を扱います。4回のレポート課題では、配布データを R や Python（Google Colab）、Excel などで実際に分析します。社会調査士資格のE科目（多変量解析の方法に関する科目）に対応していました。
